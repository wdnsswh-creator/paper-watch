# 滨海湿地土壤氮转化过程对不同形态和水平氮素添加的响应及其调控机制

## 摘要初稿

滨海湿地是陆海相互作用强烈的关键生态系统，其土壤氮转化过程受外源氮输入、盐分梯度、含水状态和微生物功能潜力的共同调控。为阐明不同氮形态和添加水平对黄河三角洲滨海湿地土壤氮循环过程的影响，本研究以 NH4+-N 和 NO3--N 添加处理为核心，结合土壤氮循环功能基因丰度、氮循环模块、群落差异检验以及环境因子相关性分析，系统评估土壤微生物介导氮转化过程的响应特征。结果表明，不同氮添加处理并未显著改变土壤氮循环功能基因整体组成结构，PERMANOVA 分析显示处理因子的解释率为 7.66%，但未达到显著水平（R2 = 0.0766，F = 0.871，P = 0.571）；ANOSIM 结果同样显示组间分离程度较弱（R = 0.0638，P = 0.155）。然而，在单个土壤氮循环功能基因层面，反硝化相关基因 `nirK` 和 `nosZ` 以及 DNRA 相关基因 `nrfA` 对特定氮形态和添加水平表现出显著响应。其中，NH3 处理显著提高 `nirK` 和 `nosZ` 丰度，NO2 处理显著提高 `nirK`、`nosZ` 和 `nrfA` 丰度，说明中高水平氮添加可能优先影响反硝化和 DNRA 相关微生物功能潜力。相关性分析进一步显示，TN、C:N、NH4+-N、NO3--N、pH 和 EC 与多种土壤氮循环功能基因存在显著关联，提示底物供给、盐分条件和酸碱环境可能共同参与调控滨海湿地土壤氮转化过程。总体来看，滨海湿地土壤氮循环功能响应并非表现为整体群落结构的同步改变，而更可能体现为特定氮转化环节和关键基因的选择性响应。

关键词：滨海湿地；氮添加；NH4+-N；NO3--N；土壤氮循环功能基因；反硝化；DNRA；黄河三角洲

## 1 引言初稿

全球氮沉降和人为氮输入持续增强，正在改变湿地生态系统的养分限制格局和微生物介导的生物地球化学过程。滨海湿地处于陆地、河流和海洋交汇区，兼具高生产力、高盐分波动和强氧化还原梯度等特征，是氮截留、转化和释放的重要场所。与内陆生态系统相比，滨海湿地土壤氮循环不仅受外源氮输入影响，还受到盐度、pH、含水率、潮汐扰动和植被根际过程的共同制约。因此，解析不同氮形态和添加水平下土壤氮转化过程的响应机制，对于认识滨海湿地氮循环稳定性及其生态环境效应具有重要意义。

微生物是土壤氮转化过程的直接驱动者。硝化/氨氧化、反硝化、DNRA 和固氮等过程分别由不同功能类群及其相关土壤氮循环功能基因参与调控。其中，`pmoA-amoA`、`pmoB-amoB`、`pmoC-amoC` 和 `hao` 常用于表征硝化或氨氧化潜力；`napA`、`nirK`、`nirS`、`norB`、`norC` 和 `nosZ` 反映反硝化链条不同环节；`nrfA` 是 DNRA 过程的重要指示基因；`nifH`、`nifD` 和 `nifK` 则与生物固氮潜力密切相关。已有研究表明，外源氮输入能够通过改变底物供给和微生物生态位影响土壤微生物群落及其功能基因组成，但其响应方向通常受到氮形态、添加水平和土壤背景条件的共同调控（Ao et al., 2025；Ma et al., 2021）。

黄河三角洲滨海湿地具有明显的盐碱化背景和强烈的水盐动态变化，不同形态氮输入可能对硝化、反硝化、DNRA 和固氮过程产生差异化影响。NH4+-N 可作为氨氧化过程的直接底物，而 NO3--N 则与反硝化和 DNRA 过程密切相关。因此，本研究围绕“滨海湿地土壤氮转化过程对不同形态和水平氮素添加的响应及其调控机制”这一主题，结合土壤氮循环功能基因、氮循环模块和环境因子相关性结果，重点回答以下问题：不同氮形态和添加水平是否改变土壤氮循环功能基因整体组成；哪些关键土壤氮循环功能基因对氮添加最敏感；环境因子与这些基因之间是否存在显著关联；以及这些结果如何解释滨海湿地土壤氮转化过程的潜在调控机制。

## 2 结果初稿

### 2.1 土壤氮循环功能基因整体组成对氮添加的响应

基于土壤氮循环功能基因整体组成的多变量检验结果显示，不同氮添加处理之间的整体分异并不显著。PERMANOVA 分析表明，处理因子对土壤氮循环功能基因组成的解释率为 7.66%，但未达到显著水平（R2 = 0.0766，F = 0.871，P = 0.571）。ANOSIM 分析也得到一致结果，组间差异强度较低且不显著（R = 0.0638，P = 0.155）。这些结果说明，在当前数据条件下，不同氮形态和添加水平尚不足以驱动土壤氮循环功能基因整体组成发生显著分离，整体功能谱更可能保持相对稳定。

尽管整体组成差异不显著，单个土壤氮循环功能基因仍表现出较强的处理依赖性。换言之，氮添加对滨海湿地土壤氮循环的影响并非体现为全部基因的同步变化，而是集中表现为少数关键氮转化环节的选择性响应。这种“整体结构不显著、局部基因显著响应”的模式在微生物功能研究中具有生态学意义，说明土壤微生物功能潜力可能通过关键过程节点的调整来响应外源氮输入，而非通过整体功能组成的剧烈重组完成适应。

### 2.2 硝化/氨氧化相关土壤氮循环功能基因

硝化/氨氧化相关基因中，`hao` 在 NO2 处理中平均丰度最高（1764.00），在 NO1 处理中最低（994.67）。与各自对照相比，NH4+-N 和 NO3--N 添加下 `hao` 均未检出显著差异，显著性字母均为 a，P 值结果也未显示显著变化。因此，当前结果只能表述为 `hao` 在不同氮添加处理中呈一定波动趋势，不能写作显著增加或显著降低。该结果提示，氨氧化后续步骤相关潜力可能对氮添加具有响应趋势，但其显著性仍需结合更高统计功效或过程速率数据进一步核对。

从氮形态角度看，NO2 处理下 `hao` 的均值高于 CK2，而 NO1 处理下均值低于 CK2，说明 NO3--N 添加水平可能影响硝化/氨氧化相关潜力的方向和幅度。然而，由于缺少显著性支持，本研究仅将其解释为氮添加水平依赖性趋势。该结果可在正式论文中与硝化/氨氧化相关图件共同呈现，表述为“见土壤氮循环功能基因柱状图，图号待定”。

### 2.3 反硝化相关土壤氮循环功能基因

反硝化相关土壤氮循环功能基因对氮添加表现出更明显的响应。`nirK` 在 NO2 处理中达到最高均值（4709.33），在 CK2 处理中最低（2604.00）。显著性检验显示，NH3 处理下 `nirK` 丰度显著高于 CK1（P = 0.0059），NO2 处理下 `nirK` 丰度显著高于 CK2（P = 0.0162）。同时，显著性字母显示 CK2 和 NO1 为 b，NO2 为 a，NO3 为 ab，进一步说明 NO3--N 添加下 `nirK` 的响应具有明显的氮添加水平依赖性。该结果表明，高水平 NH4+-N 添加和中水平 NO3--N 添加均可增强与亚硝酸盐还原相关的反硝化潜力，且 NO3--N 添加下的响应并非随添加水平线性增强，而更可能存在中等添加水平下的峰值响应。

`nirS` 的最高均值出现在 NH2 处理（1738.67），最低均值出现在 NO1 处理（1129.33），但当前显著性结果未支持其在处理间存在显著差异。因此，`nirS` 只能表述为在不同氮添加处理下呈波动变化趋势。`norB` 在 NO3 处理中均值最高（1633.33），在 NO1 处理中最低（1084.00）；`norC` 在 CK1 中均值最高（173.33），在 NO1 中最低（126.67）。由于这两个基因缺少明确显著性支持，正式结果段应避免写作显著变化，而应表述为“呈处理依赖性变化趋势，显著性仍需进一步核对”。

`nosZ` 是反硝化过程中 N2O 还原为 N2 的关键土壤氮循环功能基因。结果显示，`nosZ` 在 NH3 处理中均值最高（2076.00），在 NO1 处理中最低（1218.67）。显著性检验表明，NH3 处理显著提高 `nosZ` 丰度（相对于 CK1，P = 0.0273），NO2 处理也显著提高 `nosZ` 丰度（相对于 CK2，P = 0.0255）。该结果说明，特定氮形态和添加水平可能增强反硝化末端还原潜力。由于 `nirK` 与 `nosZ` 均在 NH3 和 NO2 处理中表现出显著升高，说明高水平 NH4+-N 添加和中水平 NO3--N 添加可能同步影响反硝化链条中亚硝酸盐还原和氧化亚氮还原两个关键环节，反映出较强的氮形态依赖性和氮添加水平依赖性。

### 2.4 DNRA 相关土壤氮循环功能基因

DNRA 相关基因 `nrfA` 在 NO2 处理中均值最高（393.33），在 CK2 处理中最低（260.00）。显著性检验显示，NO2 处理显著提高 `nrfA` 丰度（相对于 CK2，P = 0.0434），而 NH4+-N 添加处理未检出显著变化。该结果说明，中水平 NO3--N 添加不仅影响反硝化相关基因，也可能增强硝酸盐异化还原为铵过程的功能潜力。由于 DNRA 与反硝化均以硝酸盐或亚硝酸盐为重要底物，NO2 处理中 `nirK`、`nosZ` 和 `nrfA` 同时升高，提示 NO3--N 输入可能改变滨海湿地土壤中硝酸盐还原过程的分配格局。

需要强调的是，本研究基于基因丰度数据只能说明 DNRA 相关功能潜力发生变化，不能直接推断实际 DNRA 过程速率增加。若后续能够补充同位素示踪或氮转化速率测定，将有助于进一步判断 NO3--N 添加是否真正促进 DNRA 通量。

### 2.5 固氮相关土壤氮循环功能基因

固氮相关基因 `nifD`、`nifH` 和 `nifK` 在不同处理间均未检出显著差异。均值上，三者均在 CK2 处理中较高，分别为 130.67、248.00 和 258.67，而在 NH3 或 NH2 处理中较低。其中，`nifD` 和 `nifH` 在 NH3 处理中最低，`nifK` 在 NH2 处理中最低。这一结果说明，NH4+-N 添加下固氮相关土壤氮循环功能基因可能呈下降趋势，但由于显著性字母均未显示差异，不能写作显著降低。

从生态机制上看，外源氮输入可能降低微生物对生物固氮的需求，这是固氮基因下降趋势的可能解释之一。然而，在当前数据中该趋势尚未达到显著水平，因此讨论中应使用谨慎表达，例如“可能削弱固氮潜力”或“呈降低趋势”，而不能表述为“氮添加显著抑制固氮过程”。

### 2.6 氮循环模块响应特征

氮循环模块结果进一步显示，不同氮转化过程对氮添加的响应方向并不一致。硝化模块在 NO_Mid 处理中均值最高（1764.00），在 NO_Low 处理中最低（994.67）；反硝化模块同样在 NO_Mid 处理中最高（9957.33），在 NO_Low 处理中最低（6290.67）；DNRA 模块也在 NO_Mid 处理中达到最高值（641.33），在 NO_Low 处理中最低（404.00）。这些结果与单基因层面的 `nirK`、`nosZ` 和 `nrfA` 响应相互印证，提示中水平 NO3--N 添加可能是驱动硝酸盐还原相关过程增强的关键处理。

与之相比，氨同化模块在 NH_Low 处理中最高（8028.67），在 CK2 处理中最低（5407.33）；固氮模块在 CK2 中最高（637.33），在 NH_Mid 中最低（376.67）；尿素分解模块在 CK1 中最高（892.00），在 NH_Mid 中最低（644.00）。由于模块数据主要提供均值和标准差，缺少配套 P 值或显著性字母，以上结果应作为趋势描述。整体来看，模块结果支持“不同氮形态和添加水平对氮循环过程的调控并不一致”这一判断，其中 NO3--N 添加更可能影响硝化、反硝化和 DNRA 相关模块，而 NH4+-N 添加可能更多影响氨同化和固氮相关潜力。

### 2.7 环境因子与土壤氮循环功能基因的关联

相关性热图显示，多个环境因子与土壤氮循环功能基因之间存在显著关联。TN 与 `norC` 呈显著正相关（r = 0.619，P = 0.0012），并与 `nirS`（r = 0.578，P = 0.0031）、`norB`（r = 0.569，P = 0.0037）和 `nrtD`（r = 0.487，P = 0.0157）呈显著正相关，说明总氮水平可能与反硝化和氮转运相关功能潜力密切关联。C:N 与 `nirS`（r = -0.605，P = 0.0021）、`norB`（r = -0.577，P = 0.0032）、`norC`（r = -0.572，P = 0.0035）和 `nrtD`（r = -0.542，P = 0.0070）呈显著负相关，提示碳氮计量关系可能参与调节反硝化相关基因的分布。

无机氮形态也与关键土壤氮循环功能基因显著相关。NO3--N 与 `amoC` 呈显著正相关（r = 0.588，P = 0.0025），并与 `narH` 和 `gltD` 呈显著正相关；NH4+-N 与 `narH`（r = 0.594，P = 0.0027）、`narG`（r = 0.528，P = 0.0080）、`narI`（r = 0.523，P = 0.0095）和 `nrfH`（r = 0.460，P = 0.0238）呈显著正相关。这些结果说明 NH4+-N 和 NO3--N 不仅作为底物或氮源影响氮转化过程，还可能通过改变微生物可利用氮形态影响反硝化、DNRA 和氮同化相关基因。

pH 与 `nirK_related` 呈显著正相关（r = 0.494，P = 0.0142），EC 与 `nirK_related` 呈显著负相关（r = -0.483，P = 0.0169），说明酸碱条件和盐分梯度可能共同影响亚硝酸盐还原相关功能潜力。考虑到滨海湿地盐碱环境的特殊性，这一结果提示 EC 和 pH 应作为解释黄河三角洲滨海湿地氮转化差异的重要环境背景。需要注意的是，相关性分析只能说明环境因子与土壤氮循环功能基因之间存在关联，不能直接表述为环境因子导致基因丰度变化。

## 3 讨论初稿

### 3.1 氮添加对土壤氮循环功能基因的影响具有过程选择性

本研究结果显示，氮添加并未显著改变土壤氮循环功能基因整体组成，但对部分关键基因产生了显著影响。这种结果说明，滨海湿地土壤微生物功能潜力对外源氮输入的响应具有明显过程选择性。与整体群落结构相比，特定土壤氮循环功能基因可能对底物变化更加敏感，尤其是反硝化和 DNRA 相关基因更容易在特定氮形态和添加水平下发生响应。

NH3 处理显著提高 `nirK` 和 `nosZ`，说明高水平 NH4+-N 添加可能通过增强氮底物供应或改变土壤微环境，促进反硝化相关功能潜力。NO2 处理显著提高 `nirK`、`nosZ` 和 `nrfA`，表明中水平 NO3--N 添加可能同时影响反硝化和 DNRA 两条硝酸盐还原路径。该结果与已有研究关于氮输入能够改变微生物氮循环功能潜力的认识一致，但也进一步强调了氮形态和添加水平的重要性（Ao et al., 2025；Ma et al., 2021；Tang et al., 2024）。

### 3.2 NO3--N 添加可能强化硝酸盐还原相关过程

NO2 处理下 `nirK`、`nosZ` 和 `nrfA` 同时显著升高，是本研究最值得关注的结果之一。`nirK` 参与亚硝酸盐还原，`nosZ` 参与 N2O 还原，`nrfA` 则与 DNRA 过程相关。这说明中水平 NO3--N 添加可能增强硝酸盐还原过程中的多个关键环节。由于 NO3--N 是反硝化和 DNRA 的重要底物，该结果具有较强的过程合理性。

不过，反硝化和 DNRA 之间存在底物竞争关系，仅凭基因丰度不能判断氮最终以 N2、N2O 或 NH4+-N 形式保留或释放。因此，正式讨论中应将其表述为“NO3--N 添加可能提高硝酸盐还原相关功能潜力”，而不能直接推断实际氮气释放或铵态氮保留量增加。若后续补充 N2O 排放、净矿化/硝化速率或同位素示踪数据，可进一步验证该推断。

### 3.3 固氮潜力可能对外源氮输入呈弱化趋势

固氮相关基因 `nifD`、`nifH` 和 `nifK` 在 NH4+-N 添加处理中整体呈较低趋势，尤其 `nifD` 和 `nifH` 在 NH3 处理中最低，`nifK` 在 NH2 处理中最低。虽然该趋势未达到显著水平，但从生态学机制上看，外源氮输入可能降低微生物对固氮过程的依赖，从而使固氮相关功能潜力下降。类似现象在氮添加影响微生物功能基因的研究中已有报道，但具体方向常受生态系统类型和土壤背景限制（Ao et al., 2025；Ma et al., 2021）。

在本文中，固氮相关结果应作为趋势性发现处理。更稳妥的表述是：NH4+-N 添加下固氮相关土壤氮循环功能基因呈下降趋势，提示外源氮输入可能削弱固氮潜力，但该趋势尚需更多重复和显著性检验支持。

### 3.4 环境因子可能参与调控滨海湿地氮转化过程

相关性结果显示，TN、C:N、NH4+-N、NO3--N、pH 和 EC 均与部分土壤氮循环功能基因显著相关，说明氮循环功能潜力并非只受外源氮添加影响，还受到土壤理化环境共同调控。TN 与多个反硝化相关基因呈正相关，C:N 与这些基因呈负相关，说明氮供应和碳氮计量关系可能共同影响反硝化相关功能潜力。NH4+-N 和 NO3--N 与 `narG`、`narH`、`narI`、`nrfH`、`amoC` 等基因的显著关联，则进一步支持无机氮形态在调节氮转化过程中的重要作用。

滨海湿地中，EC 和 pH 是反映盐碱环境的重要指标。本研究中 EC 与 `nirK_related` 呈负相关，而 pH 与 `nirK_related` 呈正相关，说明盐分和酸碱条件可能改变反硝化相关微生物功能潜力。由于黄河三角洲滨海湿地具有典型盐碱化背景，环境因子调控很可能是解释不同氮添加处理响应差异的重要机制之一。

## 4 小结初稿

综上，本研究表明，不同形态和水平氮添加对黄河三角洲滨海湿地土壤氮循环功能的影响具有明显的基因特异性和过程选择性。整体上，氮添加未显著改变土壤氮循环功能基因组成结构，但高水平 NH4+-N 添加显著提高反硝化相关基因 `nirK` 和 `nosZ`，中水平 NO3--N 添加显著提高 `nirK`、`nosZ` 和 DNRA 相关基因 `nrfA`。氮循环模块结果进一步显示，NO_Mid 处理下硝化、反硝化和 DNRA 模块均呈较高趋势，提示 NO3--N 添加可能优先影响硝酸盐还原相关过程。相关性分析显示 TN、C:N、NH4+-N、NO3--N、pH 和 EC 与多种土壤氮循环功能基因显著关联，说明底物供应、盐分条件和酸碱环境可能共同参与调控滨海湿地土壤氮转化过程。

需要指出的是，当前结果主要基于土壤氮循环功能基因丰度和相关性分析，能够反映潜在功能变化，但尚不能直接代表实际氮转化速率。正式论文写作中，对于未达到显著水平的基因和模块应使用“呈升高趋势”“呈下降趋势”或“需进一步核对显著性”等表达；对于 RDA 和相关性结果，应使用“相关”“关联”或“可能参与调控”，避免写作“导致”。后续若结合氮转化速率、N2O 排放或同位素示踪结果，将有助于进一步阐明不同氮形态和添加水平调控滨海湿地土壤氮转化过程的机制。

## 可直接用于结果段的精简版

不同氮添加处理未显著改变土壤氮循环功能基因整体组成。PERMANOVA 结果显示，处理因子的解释率为 7.66%，但未达到显著水平（R2 = 0.0766，F = 0.871，P = 0.571）；ANOSIM 结果同样显示组间分离较弱（R = 0.0638，P = 0.155）。然而，单个土壤氮循环功能基因对特定氮添加处理表现出显著响应。与 CK1 相比，NH3 处理显著提高反硝化相关基因 `nirK`（P = 0.0059）和 `nosZ`（P = 0.0273）的丰度；与 CK2 相比，NO2 处理显著提高 `nirK`（P = 0.0162）、`nosZ`（P = 0.0255）和 DNRA 相关基因 `nrfA`（P = 0.0434）的丰度。相比之下，`hao`、`nirS`、`norB`、`norC` 以及固氮相关基因 `nifD`、`nifH` 和 `nifK` 在不同处理间主要表现为变化趋势，未检出明确显著差异。上述结果说明，不同氮形态和添加水平对滨海湿地土壤氮循环功能基因的影响具有明显处理依赖性，其中高水平 NH4+-N 添加和中水平 NO3--N 添加可能优先增强反硝化及 DNRA 相关功能潜力，相关结果见土壤氮循环功能基因柱状图（图号待定）。

## 可直接用于讨论段的精简版

本研究发现，氮添加对土壤氮循环功能基因的影响并非表现为整体功能组成的显著分离，而是集中体现在少数关键基因的选择性响应上。NH3 处理下 `nirK` 和 `nosZ` 显著升高，NO2 处理下 `nirK`、`nosZ` 和 `nrfA` 显著升高，表明反硝化和 DNRA 相关过程可能是滨海湿地土壤微生物响应外源氮输入的敏感环节。由于 `nirK` 和 `nosZ` 分别参与反硝化过程中的亚硝酸盐还原和 N2O 还原，二者同步升高可能意味着高水平 NH4+-N 添加和中水平 NO3--N 添加增强了反硝化链条的潜在功能。与此同时，`nrfA` 在 NO2 处理下显著升高，提示 NO3--N 添加还可能影响 DNRA 过程。相关性分析中 TN、C:N、NH4+-N、NO3--N、pH 和 EC 与多种土壤氮循环功能基因显著相关，进一步说明滨海湿地土壤氮转化过程受到底物供给与盐碱环境的共同调控。需要注意的是，基因丰度和环境相关性只能反映潜在功能及其关联关系，不能直接推断实际过程速率或因果关系。
