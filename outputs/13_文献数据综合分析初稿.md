## 一、Zotero 文献总体概况

本次共解析 Zotero RIS 文献 316 条。

按主题自动分类后，主要文献类型包括：环境因子调控 231 条；湿地植被与根际效应 116 条；滨海湿地与盐沼生态系统 101 条；微生物群落结构与共现网络 76 条；土壤氮循环功能基因与宏基因组 58 条；氮添加/氮沉降与微生物群落 54 条；背景文献 31 条；硝化与氨氧化过程 20 条。

## 二、文献分析语言模板

### 2.1 氮添加/氮沉降与微生物群落

- 外源氮输入能够改变土壤养分供给和微生物生态位，从而影响微生物群落组成与功能潜力。（Ao et al., 2025；Ma et al., 2021）
- 氮添加效应通常受添加形态、添加水平和土壤背景共同制约，不同生态系统中微生物群落响应方向并不完全一致。（Ao et al., 2025；Ma et al., 2021）
- 在讨论氮添加结果时，应区分 NH4+-N 与 NO3--N 的形态差异，并结合处理水平解释群落或功能变化。（Ao et al., 2025；Ma et al., 2021）

### 2.2 土壤氮循环功能基因与宏基因组

- 宏基因组和土壤氮循环功能基因丰度可用于表征微生物介导氮转化过程的潜在功能基础。（Ao et al., 2025；Ma et al., 2021）
- 土壤氮循环功能基因的变化能够将群落结构差异与硝化、反硝化、DNRA 和固氮等过程联系起来。（Ao et al., 2025；Ma et al., 2021）
- 相较于单一环境因子，土壤氮循环功能基因更适合解释外源氮输入对潜在氮转化路径的影响。（Ao et al., 2025；Ma et al., 2021）

### 2.3 硝化与氨氧化过程

- pmoA-amoA、pmoB-amoB、pmoC-amoC 和 hao 等土壤氮循环功能基因常被用于指示硝化或氨氧化相关潜力。（Ao et al., 2025；Ma et al., 2021）
- NH4+-N 可作为氨氧化底物，因此其添加可能改变硝化相关土壤氮循环功能基因的丰度或组成。（Ao et al., 2025；Ma et al., 2021）
- 当硝化相关基因仅呈趋势变化而缺少显著性时，应表述为潜在硝化过程可能发生响应，不能直接判断显著增强。（Ao et al., 2025；Ma et al., 2021）

### 2.4 反硝化过程

- napA、nirK、nirS、norB、norC 和 nosZ 等土壤氮循环功能基因共同反映反硝化链条不同步骤的潜在变化。（Hayatsu et al., 2021；Tang et al., 2024）
- 反硝化过程受 NO3--N 供给、碳源、含水率和氧化还原环境共同影响，因此其响应具有明显环境依赖性。（Hayatsu et al., 2021；Tang et al., 2024）
- 若反硝化相关土壤氮循环功能基因在不同处理间方向不一致，可解释为氮形态或添加水平对反硝化链条存在分段调控。（Hayatsu et al., 2021；Tang et al., 2024）

### 2.5 DNRA 与硝酸盐还原过程

- nrfA 等土壤氮循环功能基因可用于指示 DNRA 或硝酸盐还原为铵的潜在过程。（Ao et al., 2025；Ma et al., 2021）
- DNRA 与反硝化同样依赖硝酸盐底物，但其相对优势可能受碳氮比和还原环境调节。（Ao et al., 2025；Ma et al., 2021）
- 当 nrfA 或 nrfH 与无机氮、C:N 等因子相关时，可表述为这些因子可能参与 DNRA 过程调控。（Ao et al., 2025；Ma et al., 2021）

### 2.6 固氮过程

- nifH、nifD 和 nifK 是表征固氮潜力的重要土壤氮循环功能基因。（Ao et al., 2025；Ma et al., 2021）
- 外源氮输入可能降低微生物对固氮过程的依赖，但不同湿地土壤中该响应仍受环境背景限制。（Ao et al., 2025；Ma et al., 2021）
- 若固氮相关基因在氮添加处理下下降，可从氮素供给增加削弱固氮需求的角度进行讨论，但需以显著性结果为依据。（Ao et al., 2025；Ma et al., 2021）

### 2.7 滨海湿地与盐沼生态系统

- 滨海湿地和盐沼位于陆海交互带，盐分、水分和植被格局共同影响土壤氮循环过程。（Ao et al., 2025；Hanley et al., 2021）
- 黄河三角洲滨海湿地的氮转化过程需要结合盐碱环境和潮滩水文背景进行解释。（Ao et al., 2025；Hanley et al., 2021）
- 湿地土壤中氮循环响应往往体现为环境梯度与微生物功能潜力共同作用的结果。（Ao et al., 2025；Hanley et al., 2021）

### 2.8 环境因子调控

- pH、EC、含水率和无机氮形态可通过改变底物供给与微生境条件影响土壤氮循环功能基因。（Ao et al., 2025；Ma et al., 2021）
- 相关性或 RDA 结果只能说明环境因子与土壤氮循环功能基因存在关联或可能参与调控，不能直接证明因果关系。（Ao et al., 2025；Ma et al., 2021）
- 在滨海湿地盐碱背景下，EC 和 pH 对反硝化、DNRA 或尿素分解相关基因的影响尤其需要结合过程机制解释。（Ao et al., 2025；Ma et al., 2021）

### 2.9 湿地植被与根际效应

- 湿地植被和根际过程能够通过有机碳输入、氧释放和微生境改变影响微生物群落与土壤氮循环功能基因。（Ao et al., 2025；Ma et al., 2021）
- 互花米草入侵或植被演替可能改变滨海湿地土壤养分状态，并进一步影响氮转化相关微生物过程。（Ao et al., 2025；Ma et al., 2021）
- 若样地存在不同植被类型，讨论中应将植被效应作为解释氮循环差异的重要背景因素。（Ao et al., 2025；Ma et al., 2021）

### 2.10 微生物群落结构与共现网络

- 微生物群落结构变化可与土壤氮循环功能基因丰度共同用于解释氮转化过程的潜在生态机制。（Ao et al., 2025；Ma et al., 2021）
- 共现网络可用于描述微生物类群之间的关联结构，但网络关系不等同于直接互作或因果调控。（Ao et al., 2025；Ma et al., 2021）
- 当群落排序结果不显著而部分基因显著变化时，应强调功能响应的局部性和过程选择性。（Ao et al., 2025；Ma et al., 2021）

## 九、讨论段可用语言

- 不同氮添加处理对土壤氮循环功能基因的影响更突出地体现为特定氮转化过程的响应差异，应结合显著性和趋势变化进行讨论（Ao et al., 2025；Ma et al., 2021）。
- NH4+-N 与 NO3--N 添加产生差异响应时，可从底物形态和硝化-反硝化耦合关系解释，但不能在缺少过程速率数据时直接推断实际通量（Ao et al., 2025；Hayatsu et al., 2021）。
- RDA 或相关性热图只能支持环境因子与土壤氮循环功能基因之间存在关联或可能参与调控，不能直接写作导致（Ao et al., 2025；Ma et al., 2021）。

## 十、章节结尾段模板

- 本节结果表明，不同氮添加处理对土壤氮循环功能基因的影响具有明显过程差异。部分基因或模块在特定氮形态和添加水平下呈升高或下降趋势，而整体排序检验并不一定达到显著水平。
- 这些结果提示，滨海湿地土壤氮转化过程并非对外源氮输入作出单一方向响应，而是在 NH4+-N 与 NO3--N 添加、低中高添加水平以及环境因子共同作用下表现出处理依赖性。
- 对于缺少显著性检验的数据，只能作为响应趋势讨论；对于 P<0.05 或显著性字母不同的结果，才可进一步提炼其生态意义并进入机制讨论。
